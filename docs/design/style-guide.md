# ZeroJance Style Guide (D2)

Owner: Creative Director. Task D2 (`feat/design-tokens`). Files: `docs/design/tokens.css` (values), this file (rules), `docs/design/tools/check-contrast.py` (verifier), `docs/design/assets/` (SVGs).
Builds on `concept.md` (sections 3 and 7). The site name is ZeroJance in prose and `ZEROJANCE` in the terminal, tags and rail.

**How the Frontend Engineer uses this:** copy `tokens.css` unchanged to `apps/web/src/styles/tokens.css`. Components use only `var(--zj-*)`; no raw hex, no magic numbers for spacing, duration, easing or z-index. Ship it as a real stylesheet file, never as an inline `<style>` or `style=""` (the site is CSP-clean, see the roadmap). To change a value, ask the Creative Director.

---

## 1. Principles
1. **Color is grammar.** Each ink has one meaning (section 2). Decoration is not a meaning.
2. **Text stays legible first.** Body text at least 4.5:1, large text and controls at least 3:1, verified by script (section 3), not by eye.
3. **Nothing carries meaning by color alone.** Every colored signal also has words (`[ ok ]`, `uplink down`), an underline, or an outline.
4. **Effects are values, not decoration.** Motion tokens exist; whether an effect runs is decided by `prefers-reduced-motion` and by D3's catalog.
5. **One family, one scale.** System monospace only, one type scale, one spacing scale, one z-index scale.

## 2. Color

Dark only in the MVP (`color-scheme: dark`, `<meta name="color-scheme" content="dark">`, `<meta name="theme-color" content="#0B0D10">`). No light theme.

Rules:
- No gradients except `--zj-hazard-tape`. No glow, bloom, `text-shadow`, or `filter` on text.
- Never lower text contrast with `opacity`. To dim, use `--zj-fg-dim`.
- Hazard tape (`--zj-hazard-tape`) appears only as a 4px strip on the operator prompt and above back-room command output. Never behind text; never for warnings (that is what `[warn]` is for).
- Vermilion is reserved for real faults. If you are tempted to use it for emphasis, use bone plus a tag.
- No cyan, no magenta, no pure white `#FFFFFF`, no pure black `#000000`.

## 3. Contrast (computed)

Method: WCAG 2.x relative luminance, `(L1 + 0.05) / (L2 + 0.05)`. Thresholds: text 4.5:1; large text and UI or graphics 3:1. Generated by `python3 docs/design/tools/check-contrast.py` (reads the hex values from `tokens.css`, exits non-zero on any failure). Last run for this branch: 0 failures. Add a row to `PAIRS` in the script whenever a new color pairing is used; **a pairing that is not in this table is not allowed.**

## 4. Typography

System font stack only (`--zj-font-mono`, one family on purpose): `ui-monospace, "SF Mono", SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "DejaVu Sans Mono", "Courier New", monospace`. No `@font-face`, no font requests.

| Token | Size | Use |
|---|---|---|
| `--zj-text-xs` | 12px | Rail chrome and `T+` clock only; never body or anything a visitor must read to act |
| `--zj-text-sm` | 14px | Tags, chips, secondary output |
| `--zj-text-md` | 16px | Output and the prompt line (16px also stops iOS zoom on input focus) |
| `--zj-text-lg` | 20px | Banner subtitle |
| `--zj-text-xl` | 24px | Banner title `ZEROJANCE` |

- Weight: 400 everywhere; 700 for tags and the banner title only.
- Line height: `--zj-leading-body` 1.5 for output, `--zj-leading-tight` 1.25 for the banner.
- Uppercase is for identifiers and tags (`ZEROJANCE`, `TRANSIENT-4F2A`, `[ ok ]`) with `letter-spacing: var(--zj-tracking-tag)`. Prose is sentence case.
- Set on the terminal: `font-variant-ligatures: none; tab-size: var(--zj-tab-size); -webkit-text-size-adjust: 100%`.
- Output lines: `white-space: pre-wrap; overflow-wrap: anywhere;` so long visitor text wraps instead of overflowing. Max column `--zj-measure` (80ch); system copy is written to wrap under 72 characters.
- Visitor text is always a text node in the same font and `--zj-fg`; never styled from its content.

## 5. Spacing and layout

Scale (`--zj-space-0` to `-8`): 0, 4, 8, 12, 16, 24, 32, 48, 64 px (in rem). Rules:
- Page gutter `--zj-gutter` is 16px on mobile; use `--zj-space-6` (32px) at 48em and wider.
- Space between output blocks: `--zj-space-3`; between lines inside a block: 0 (line height does the work).
- Touch targets at least `--zj-tap-min` (44px) high: chips, prompt tap area.
- Status rail height `--zj-rail-height` (36px).
- Radius: `--zj-radius` (2px) on chips only; everything else square. Borders 1px (`--zj-border-width`).
- Mobile first. Nothing may require horizontal page scroll at 320px.

## 6. Motion

| Token | Value | Use |
|---|---|---|
| `--zj-dur-instant` | 0ms | No transition |
| `--zj-dur-fast` | 100ms | Hover/press feedback |
| `--zj-dur-base` | 180ms | State changes, chip highlight |
| `--zj-dur-slow` | 360ms | Fault transition, sweep color change |
| `--zj-dur-boot-line` | 60ms | Gap between boot lines |
| `--zj-dur-type-char` | 14ms | Per character when typing boot/banner text |
| `--zj-dur-boot-max` | 5000ms | Hard ceiling for the whole first-visit boot |
| `--zj-dur-reconnect` | 1200ms | Returning visitor's short boot |
| `--zj-cursor-period` | 1060ms | Cursor blink cycle (uses `--zj-ease-step`) |
| `--zj-sweep-period-ok` / `-slow` | 4000ms / 9000ms | One sweep turn (uses `--zj-ease-linear`) |

Easings: `--zj-ease-out` `cubic-bezier(0.2, 0, 0, 1)` for things entering; `--zj-ease-in` `cubic-bezier(0.4, 0, 1, 1)` for things leaving; `--zj-ease-in-out` `cubic-bezier(0.4, 0, 0.2, 1)` for state swaps; `--zj-ease-linear` for the sweep; `--zj-ease-step` `steps(1, end)` for the blink.

Rules:
- Animate only `opacity` and `transform` (and `color` for the sweep state). No layout properties.
- Every animation is wrapped in `@media (prefers-reduced-motion: no-preference)`. Under `reduce`, `tokens.css` also collapses the durations to 0ms, so anything that slips through ends in its final state instantly. D3's effects catalog gives the per-effect fallback.
- No infinite animation except the cursor blink and the sweep; both stop under reduced motion (the sweep stays as a static glyph that still shows uplink state by color and rail text).
- Boot never blocks input: any key or tap skips to the final state.

## 7. Z-index

`--zj-z-base` 0, `--zj-z-terminal` 1, `--zj-z-rail` 10, `--zj-z-chips` 20, `--zj-z-boot` 40, `--zj-z-skiphint` 50, `--zj-z-skiplink` 60. Components take a token; nobody invents a number.

## 9. Assets (`docs/design/assets/`)
- `sweep-glyph.svg`: the radar sweep for the status rail. Inline it (not `<img>`) so `color` can drive it via `currentColor`: set `color` to `var(--zj-sweep-ok)`, `--zj-sweep-slow`, or `--zj-sweep-down`. The group `#sweep` is the one D3 rotates (`transform-origin: 16px 16px`, `--zj-sweep-period-*`, linear). Static state has no rotation.
- `favicon.svg`: fixed hex colors (a favicon cannot read CSS variables). The frontend links it as `<link rel="icon" type="image/svg+xml" href="/favicon.svg">` from its own `public/` copy; no external fetch.
- No raster images, no icon fonts.

## 10. Other user-preference modes
- **`prefers-contrast: more`:** handled in `tokens.css` (brighter slate and control border).
- **`forced-colors: active`:** do not fight it. Do not rely on `background-image` or `box-shadow` for essential information; use borders and outlines (they survive). The hazard tape and sweep colors are allowed to disappear because the rail text and clearance words carry the same information.
- **Zoom / large text:** all sizes are `rem`; the layout must reflow at 200% zoom and 320px width without horizontal scroll.
- **Print:** out of scope for the MVP.
