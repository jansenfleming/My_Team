# PR description files

One file per branch (`<branch-slug>.md`), written by that branch's author, used as the
real GitHub PR body when the lead pushes and opens the PR. See
`docs/architecture/ownership-map.md` for the full flow.

Files dated 2026-09-21 and earlier (`feat-api-*`, `feat-design-concept`, `feat-terminal-
engine`, the `qa-*` gate files, etc.) are from the superseded cybersecurity-terminal
project (see `docs/architecture/adr/0003-streetwear-pivot.md`). Left in place as
history; ZeroJance work adds new files here going forward.
