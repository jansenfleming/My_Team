# chore/scaffold: root workspace scaffold

Author: architect. Branch: `chore/scaffold`. Base: `main` (after `docs/architecture`).

## What changed
Root config and empty workspaces only. No application code.
- `package.json`: npm workspaces (`apps/*`, `packages/*`, `qa`), Node `>=22.12 <23`, root scripts `dev`, `build`, `test`, `typecheck`, `lint`, `audit:ci`; dev dependencies: eslint 9, typescript-eslint 8, typescript 5.9, `@types/node` 22, `globals`, `concurrently`.
- `tsconfig.base.json`: strict, ES2022, bundler module resolution, `noEmit`, `verbatimModuleSyntax` (forces `import type`).
- `eslint.config.js`: flat config, ignores `.worktrees/`, forbids `eval`, requires type-only imports.
- `.editorconfig`, `.nvmrc` (22), `.gitignore` additions (SQLite files, `apps/api/data/`).
- Stubs `apps/web`, `apps/api`, `packages/shared`, `qa`: `package.json` (`@site/*`, private, ESM) plus a short README. Ownership transfers to each workspace owner on merge (see `docs/architecture/ownership-map.md`).
- `package-lock.json` generated by `npm install`.
- ADR note about the expected ESLint deprecation warning.
- No root `README.md` was created (the remote owns that file).

## How to test
```
npm install          # exits 0, 4 workspaces linked
npm run lint         # exits 0 (nothing to lint yet except eslint.config.js)
npm run typecheck && npm test && npm run build   # succeed vacuously: no workspace defines these scripts yet
npm audit --audit-level=high                      # 0 vulnerabilities
```
